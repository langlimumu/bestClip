BestClip 使用说明
================

BestClip 是一个 Windows 剪贴板历史工具，解压即用，无需安装。

一、开始使用
------------
1. 将压缩包解压到任意目录，例如 D:\Tools\BestClip。
2. 双击 BestClip.exe。
3. 按 Ctrl + Shift + V 呼出历史面板。

如果 Windows 提示“Windows 已保护你的电脑”，请点击“更多信息” → “仍要运行”。
这是因为程序没有购买代码签名证书，不影响使用。

系统要求：Windows 10 2004 及以上 / Windows 11，系统自带 .NET Framework 4.8。

二、常用操作
------------
Ctrl + Shift + V   呼出 / 隐藏 BestClip
直接输入          搜索剪贴板内容
↑ / ↓             选择记录
Enter             粘贴到刚才的应用
Ctrl + P          固定 / 取消固定
Del               删除选中记录
Esc               依次关闭菜单、清空搜索、隐藏窗口
右键记录          粘贴 / 固定 / 删除

关闭窗口不会退出程序，BestClip 会继续在托盘记录。
要彻底退出，请右键托盘图标，选择“退出”。

三、设置
--------
点击主窗口右上角的齿轮，或托盘菜单中的“设置”。

- 呼出 BestClip：点击快捷键框，按下新的组合键（需包含 Ctrl、Alt 或 Shift 之一）。
- 自动粘贴：关闭后只把内容写回剪贴板，不自动发送 Ctrl + V。
- 开机自动启动：仅对当前 Windows 用户生效，不需要管理员权限。
- 忽略密码管理器：不记录 KeePass、1Password、Bitwarden 等工具复制的内容。
- 最大保存条数：固定（收藏）的记录不会被自动清理。
- 历史容量：同时受条数与 128 MB 总容量限制，超出后优先清理最旧的未收藏记录。
- 数据目录 / 检查更新：设置页底部可以直接打开数据目录或查看新版本。

四、数据位置
------------
%APPDATA%\BestClip\

history.json    剪贴板历史
settings.json   设置
images\         图片缓存

如果 %APPDATA% 不可写（部分公司电脑会限制），BestClip 会自动改用
程序目录下的 BestClip-data\，再不行则用 %TEMP%\BestClip\。
设置页底部的“数据目录”可以直接打开实际位置。

所有数据只保存在本机，BestClip 不会联网上传任何内容。
退出程序后删除该目录，即可清空全部数据。

五、常见问题
------------
1. 快捷键没反应？
   可能被其他软件占用。打开设置，重新录制一个组合键。

2. 自动粘贴没生效？
   1.1.3 起会先确认目标窗口已获得焦点；如果目标程序以管理员身份运行，或被安全软件
   拦截模拟按键，Windows 不允许自动粘贴。此时内容已经复制，直接按 Ctrl + V 即可。
   也可以尝试以管理员身份运行 BestClip。

3. 开机自启保存失败？
   公司安全策略可能禁止写入启动项。可手动把 BestClip.exe 的快捷方式放入
   shell:startup 目录，并在目标后加上 --autostart 参数。

4. 双击后提示“对路径 %APPDATA%\BestClip 的访问被拒绝”？
   1.1.1 起会自动回退到程序目录下的 BestClip-data\；1.1.2 起延长了剪贴板占用时的自动重试。
   也可以手动设置 BESTCLIP_DATA 环境变量指向一个可写目录。

5. 如何卸载？
   退出 BestClip，删除程序目录和 %APPDATA%\BestClip 即可。

6. 提示“剪贴板一直被其他程序占用”？
   远程桌面、DLP/安全软件、输入法等会短暂锁住剪贴板。1.1.2 起会自动重试约 4.5 秒；
   如果持续失败，请暂时关闭占用剪贴板的程序，或退出远程桌面后重试。
